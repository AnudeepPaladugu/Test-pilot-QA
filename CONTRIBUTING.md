# Project Notes

TestPilot QA is an independent work-in-progress portfolio project.

## Current focus
- Strengthen test case and test execution workflows.
- Expand regression coverage for linked defects and data exports.
- Improve cloud configuration and verify data isolation with dedicated test accounts.
- Improve accessibility, responsive behavior, and recovery from errors.

## Development
Install dependencies with `npm install`, start the Vite server with `npm run dev`, and run the available checks with `npm run lint` and `npm run build`.

Please avoid committing real Firebase credentials, service-account files, or user data.
